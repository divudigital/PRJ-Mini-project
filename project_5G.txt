2. Latency (Round Trip Time - RTT)
What it captures: The total time (in milliseconds) it takes for a data packet to travel from the user's device to the network server and back.

When it is used: Critical for real-time applications like Online Gaming, Autonomous Driving (V2X), Video Conferencing, and Remote Surgery.

Actual Telecom Thresholds:

Value	Status	Network Slice Allocation
1 ms to 5 ms	Ultra-Low (Ideal 5G)	Ideal for URLLC (Critical machine/automotive tasks).
6 ms to 25 ms	Excellent (Consumer)	Perfect for smooth mobile web browsing and premium cloud gaming.
26 ms to 50 ms	Acceptable	Standard routing performance for general applications.
Above 100 ms	Highly Degraded	Network congestion or bad routing. Will cause heavy app lag.
3. Jitter
What it captures: The statistical variance or fluctuations in packet arrival times. If packet 1 takes 10 ms and packet 2 takes 40 ms, the jitter is high.

When it is used: Used during VoNR (Voice over New Radio) calls, video streaming playback buffers, and live VoIP audio checks. High jitter causes robotic voices and choppy video blocks.

Actual Telecom Thresholds:

Value	Status	Impact on User
Below 3 ms	Excellent	Perfectly synced data delivery. Flawless audio/video streams.
3 ms to 10 ms	Acceptable	Standard performance, minor buffering handles this easily.
Above 20 ms	Critical Error	Extreme packet arrival distortion. Dropped voice frames, broken calls.
4. Download / Upload Throughput (Mbps)
What it captures: The data transmission capacity or volume delivered over the air interface per second.

When it is used: Used during high-bandwidth scenarios like 4K/8K streaming, heavy file transfers, or fixed wireless access (FWA) routers.

Actual Telecom Thresholds:

Metric	Value	Status / Use Case
Download	>300 Mbps	Excellent — Triggers eMBB slice (Enhanced Mobile Broadband).
Download	50−150 Mbps	Average — Standard consumer usage tier.
Upload	>50 Mbps	Excellent — Great for high-definition live streaming uploads.
Upload	<10 Mbps	Poor — Uploading large attachments or files will bottleneck.
